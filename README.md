# Портфолио — сайт-визитка

Адаптивный сайт-визитка/портфолио с вёрсткой на Sass (SCSS) и интерактивом на jQuery: липкая шапка с бургер-меню, карусель навыков, динамическая галерея портфолио (данные из JSON), модальное окно обратной связи с AJAX-отправкой формы и переключатель светлой/тёмной темы.

**Автор:** Илья Абрамов, группа ФИТ-241

## Технологии

- HTML5
- Sass (SCSS): модули `@use`/`@forward`, переменные, карты, функции, миксины
- jQuery
- npm / sass-cli — сборка стилей

## Структура стилей

```
scss/
├─ utils/       — переменные, брейкпоинты, функции (rem), миксины (respond-to, flex-center)
├─ base/        — сброс отступов, типографика
├─ layout/      — контейнер, шапка, навигация, секции, футер
├─ components/  — кнопка, карусель, карточки, модалка, форма, переключатель темы
├─ themes/      — карты светлой/тёмной палитры → CSS-переменные
└─ main.scss    — точка входа
```

Классы именованы по БЭМ, тема переключается через атрибут `data-theme` на `<html>` и сохраняется в `localStorage`.

## Установка и запуск с нуля

```bash
npm install
npm run build      # разовая сборка стилей в dist/css/main.css
```

Во время разработки стилей:

```bash
npm run sass:dev   # пересобирает CSS при каждом сохранении .scss
```

Затем откройте `index.html` через любой локальный сервер (например, расширение Live Server в VS Code или `npx serve .`).
