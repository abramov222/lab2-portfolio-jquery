# Лабораторная работа 2 — Динамическое поведение

## Описание проекта
Данный проект является продолжением Лабораторной работы 1. В статичную страницу-визитку было добавлено динамическое поведение с использованием библиотеки jQuery.

## Реализованный функционал (согласно ТЗ)
1. **jQuery подключен** локально/через CDN.
2. **Выпадающее меню:** реализовано для мобильных устройств (гамбургер-меню `slideToggle`).
3. **Модальное окно:** открывается по кнопке "Написать мне", закрывается по крестику и клику на оверлей.
4. **Форма обратной связи:** реализована валидация полей (RegEx для Email) и симуляция отправки через `$.ajax()`.
5. **Динамическая галерея портфолио:** карточки загружаются из `data/portfolio.json` через метод `$.getJSON()`.
6. **Анимации jQuery:** используются `fadeIn()`, `fadeOut()`, `slideToggle()`, `animate()` для скролла.
7. **Карусель навыков:** реализована прокрутка карточек с кнопками вперед/назад и автопрокруткой по интервалу.
8. **Scrollspy (Подсветка меню):** активный пункт навигации подсвечивается при скроллинге до соответствующей секции.
9. **Кнопка «Вверх»:** появляется при скролле вниз, плавно возвращает на начало страницы.

## Структура файлов
- `index.html` — основная разметка.
- `css/styles.css` — стили.
- `js/script.js` — вся логика jQuery.
- `data/portfolio.json` — данные для галереи.
